# MathMaster — ученически и учителски интерфейс

Приложение с React и Vite за учебни теми, задачи, тестове и проследяване на напредъка.

## Стартиране

От директорията `frontend`:

```powershell
npm install
npm run dev
```

Бекендът трябва да работи отделно. Адресът по подразбиране е `http://localhost:8000`.
За друг адрес задай `VITE_API_URL` във файл `.env.local`.

## Проверки

```powershell
npm test
npm run lint
npm run build
```

Компилираното приложение се записва в `dist`.
